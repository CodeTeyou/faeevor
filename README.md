# Welcome to Faeevor!

Faeevor is an application centered on keeping focus to requests

When you ask someone for something and they forget, Faeevor fixes that  by giving a digital reminder for waht you need to do.

Faeevor is Present in
- Web Instances
- Mobile Apps
- Desktop Apps

# Faeevor Mechanics

The basis of this app is transferring a "faeevor" to others

A faeevor can do one of the following to a Peer's Device
- Set an Alarm
- Push Notification
- Timed Reminder

All of these tie into the requesting system amd only stay peer-to-peer and is not saved by Database.
